# Sign out and sign out everywhere

- **Status:** done
- **Date:** 2026-11-29
- **Pages / modules:** `/cms`, `/recipes`, `/sales-tracker`, `/progress`; `server/src/modules/auth`
- **Requested by:** owner

## Summary

The owner can sign out of this browser, or of every device at once. Signing out everywhere ends sessions that would otherwise never expire (tokens have no TTL by default), e.g. on a lost phone.

## Scope

**In scope**

- `POST /auth/logout`: clears both cookies, no session needed.
- `POST /auth/logout-all`: needs a session; bumps `users.tokenVersion`, clears cookies.
- Tokens carry `ver`; `requireAuth` and `/auth/refresh` refuse older versions. Tokens issued before this change count as version 0 and keep working.
- CMS sidebar: "Sign out" and "Sign out everywhere" (confirm dialog). Owner pages: sign-out icon next to the theme toggle.

**Out of scope**

- Listing devices or ending one device's session.

## Design

See `docs/architecture/auth.md` (step 4). Cookies are cleared with the same path, `SameSite` and `Secure` they were set with.

## Changes

- Server: `tokens.ts` (`ver` claim, `verifyToken` returns `{ userId, version }`), `shared/auth/session.ts` (`currentTokenVersion`), `requireAuth.ts` (async, version check), auth repository/service/controller/routes.
- Database: `User.tokenVersion Int @default(0)`, migration `20261129120000_add_user_token_version` (not yet applied to production).
- Client: `features/auth/components/sign-out.tsx`, `logout` / `logoutEverywhere` in `features/auth/api.ts`, `authClient.postAsOwner`; buttons in `admin-shell.tsx`, `calendar-parts.tsx`, `recipe-book.tsx`, `progress.tsx`.
- Tests: logout clears cookies, logout-all needs a session, older-version tokens get 401, refresh refused after sign-out everywhere (`tests/setup.ts` mocks the version lookup). `npm run check` passes.
